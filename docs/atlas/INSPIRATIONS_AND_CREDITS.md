# AtlasBot — Inspirations, upstream origins, and credits

AtlasBot is an independent AtlasHub.SI product effort. This page identifies the **source-code origin** separately from **conceptual references**. References to other products do not claim copying their source, an endorsement, a partnership, or trademark ownership.

## Source origin — code provenance (not merely inspiration)

- **OpenBot** — original software and authors: **Synthetify Labs spółka z ograniczoną odpowiedzialnością**, with source lineage in [nightly-labs/openbot](https://github.com/nightly-labs/openbot). The AtlasBot Desktop currently contains inherited code from this project. Treat its legal provenance and any applicable notices as a separate obligation even after an authorised relicensing decision.
- **Third-party components** — see the repository [NOTICE](../../NOTICE) for copyright and distribution notices attached to other code, fonts, icons and other materials.

The project owner confirms Atlas legal counsel validated the agreement covering the AtlasBot MIT source transition on 15 November 2026. The private contract is not published here. New upstream code and third-party material still require rights review. See [the licensing decision](OPEN_SOURCE_TRANSITION.md) and [upstream intake policy](UPSTREAM_SYNC_POLICY.md).

## Independent product and design references

- **[OpenAI dots](https://openai.com/index/introducing-dots/)** — conceptual reference for persistent, always-on assistants, connected applications, delegated tasks and user review/approval. OpenAI does not develop, sponsor or endorse AtlasBot.
- **[xAI Grok Bot](https://x.ai/news/introducing-grok-bot)** — conceptual reference for personal digital teammates and agents with their own execution environments. xAI does not develop, sponsor or endorse AtlasBot.
- **[Open Cowork](https://github.com/OpenCoworkAI/open-cowork)** by OpenCoworkAI contributors — comparison/reference for an open-source desktop coworker, multi-provider workflows, tools and desktop interaction. There is no claim that its code has been imported into AtlasBot.
- **[CopilotKit](https://github.com/CopilotKit/CopilotKit)** — a project considered in earlier architecture experiments, listed as historical research only, not as a confirmed source-code dependency of the current Desktop.

## Atlas architecture

AtlasBot is the desktop experience; Atlas-Harness provides governance, Atlas-Agent/Hermes provides agent execution, and Atlas-Memory-Fabric and Atlas-Workforce describe the planned memory and multi-agent ecosystem. These integrations have their own implementation and release gates.
